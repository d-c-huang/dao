# 八象有解 · Eight Trigrams, Explained

以文化研究、知识可视化与应用实验为主线的中文交互网站。采用 React、TypeScript、Vite 与原生 CSS。首版为纯前端，无需账户、数据库或 API 密钥。

## 本地运行

```sh
npm install
npm run dev
```

打开终端显示的地址（通常为 http://127.0.0.1:5173）。

```sh
npm test
npm run build
npm run preview
```

构建产物位于 `dist/`，可以部署至任意静态网站服务。没有服务器路由重写要求。

## 功能

- 可点击的先天／后天八卦图，南上北下。
- 阴阳爻切换、自动辨卦、上下卦组合。
- 八卦图鉴、先后天并排对照。
- 卦象练习、SVG 海报导出、本机思考笔记。
- 来源页面，区分经典文本、入门解释与现代创作。
- 响应式布局、键盘焦点和减少动态效果支持。

## 内容约定

`src/data.ts` 中每个卦的三爻数组从下往上排列：初爻、二爻、三爻；1 为阳，0 为阴。SVG 渲染时反转顺序。组合时下卦在前、上卦在后。

资料参考《周易·说卦传》《系辞传》，阅读入口见网站资料页面。先后天图式采用常见通行排列，现代提示属于项目创作。网站不生成预测结果。全部六十四卦的卦名与经文解释不在首版范围内，现有功能演示其组合结构。

正文可离线运行；在线字体不可用时自动回退系统字体。资料外链需要网络。笔记只存在当前浏览器 localStorage，清除浏览器数据会删除。
