# 八象有解 · Eight Trigrams, Explained

以文化研究、知识可视化与应用实验为主线的中文交互网站。采用 React、TypeScript、Vite 与原生 CSS。首版为纯前端，无需账户、数据库或 API 密钥。

## 本地运行

```sh
npm install
npm run dev
```

打开终端显示的地址（通常为 http://127.0.0.1:5173）。

```sh
npm test
npm run build
npm run preview
```

构建产物位于 `dist/`，可以部署至任意静态网站服务。没有服务器路由重写要求。

## 功能

- 可点击的先天／后天八卦图，南上北下。
- 阴阳爻切换、自动辨卦、上下卦组合。
- 八卦图鉴、先后天并排对照。
- 六十四卦图鉴：卦序、卦名与读音、上下卦、卦辞、大象原文与入门解释；支持搜索、上下卦筛选和 8 × 8 组合表。
- 八卦与数学：二进制编码、组合计数、变爻立方体、互补与倒序、汉明距离及历史背景。
- 六十四卦与 AI 推理：64种现代情境、上下卦内外条件与核验行动、RAG／ReAct 研究入口，以及可复制和下载的离线提纲。
- 卦象练习、SVG 海报导出、本机思考笔记。
- 本地资料库，保存经典原文、历史短引、数学资料摘要及出处，可筛选、离线阅读和导出 Markdown。
- 全文资源归档：古籍完整经传、获准保存的原始 PDF、逐文件来源与 SHA-256；支持本地全文阅读和 ZIP 下载。
- 分组侧栏、全站搜索、手机抽屉导航；六十四卦与资料采用目录和阅读区，支持键盘操作与减少动态效果。

## 查阅与导航

工具栏的“搜索知识”可搜索学习主题、卦名、无声调拼音与卦序；也可使用 `Ctrl K`（macOS 为 `⌘ K`）。六十四卦页面将搜索筛选前置，宽屏同时显示目录与解析，窄屏切换“卦象目录／当前解析”。

页面地址使用 `#hexagrams`、`#ai-reasoning` 等片段，刷新和浏览器前后退保留当前栏目。资料目录可按经典、历史、数学与 AI 研究筛选。

AI页的64种情境及基础维度是项目设计的现代类比。离线工具根据问题、已有材料和所选情境卦整理提纲，没有调用模型或执行检索。结合方法与证据边界见 `docs/ai-reasoning.md`。

## 内容约定

`src/data.ts` 中每个卦的三爻数组从下往上排列：初爻、二爻、三爻；1 为阳，0 为阴。SVG 渲染时反转顺序。组合时下卦在前、上卦在后。

资料参考《周易》经文、《象传》《说卦传》《系辞传》，阅读入口见网站资料页面。先后天图式采用常见通行排列，现代提示属于项目创作。网站不生成预测结果。六十四卦按通行卦序展示卦辞及大象原文，配有项目编写的入门解释；各爻爻辞不在本次收录范围内。

数学页以阳为 1、阴为 0，并将初爻设为最低位：`N = 初爻 + 2 × 二爻 + 4 × 三爻`。二进制字符串按三爻、二爻、初爻显示。重卦编码为 `下卦数 + 8 × 上卦数`。这些编码与通行卦序编号分别使用；立方体、互补和汉明距离属于现代数学模型。

## 项目内资料

- `src/sources.ts`：网站资料库的结构化文本，包含摘录、项目释义、原文位置、网址、查阅日期及文本说明；正文打包进网站，可离线阅读。
- `docs/sources/`：各来源的本地 Markdown 摘编与索引，保留可查核的出处。
- `src/hexagrams.ts`：全部六十四卦的文本与上下卦资料；原文按每卦保留来源链接。
- `docs/sources/zhou-yi-64.md`：六十四卦卦辞、大象与出处的本地文本。
- `docs/hexagrams.md`：六十四卦阅读指南，说明上下卦、经传层次、通行卦序与数字编码。
- `src/hexagrams.test.ts`：依据独立的通行卦序表验证全部 8 × 8 上下卦对应，防止颠倒卦象。
- `src/math.ts`：与现有爻序一致的数学函数；`src/math.test.ts` 验证全部八卦、六十四组合及立方体图结构。
- `src/reasoningOutline.ts`：离线提纲生成函数；测试验证所选视角、材料状态与无效输入。
- `docs/ai-reasoning.md` 与 `docs/sources/ai-reasoning.md`：六十四卦与 AI 的结合思路、工具范围及原始研究出处。

`docs/sources/` 保留注明范围的摘录、原创整理与校录说明；完整归档另存于 `public/resources/`。两者在网站中分别以“资料摘录”和“本地全文”呈现。“导出资料摘录”保存 Markdown，“下载全文资源包”保存原文及原始文件的 ZIP。

## 全文资源文件

- `public/resources/classics/index.html`：完整经典的本地阅读目录。收录 68 个原文页面：六十四卦、周易目录及说卦、系辞上下；每页有 HTML 和 TXT，包含各爻爻辞与页面所载经传。
- `public/resources/history/`：莱布尼茨完整法文转录 HTML、Markdown、TXT；两幅链接扫描图因 HTTP 429 未保存，页面明确标注。
- `public/resources/mathematics/`：MIT 原始 6 页资料 PDF、920 页开放教材与 NIST 全文。完整 MIT 教材是 Berkeley 讲义的补充阅读，并非该原件。
- `public/resources/ai/`：ReAct v3 原始 PDF 与许可、署名说明。
- `public/resources/manifest.json`：146 个内容文件的来源、保存范围、许可、字节数、SHA-256，以及未归档项目的明确原因。
- `public/resources/source-archive.zip`：可下载、可离线解压阅读的全文资源包。

十条来源中七条完整归档；莱布尼茨文字完整但缺两幅链接图版，RAG 论文与 Berkeley 原件未核实允许全文再分发的许可，保留摘要和原始链接。归档不等于镜像来源站点的界面、服务及全部媒体。

已下载文件不需网络即可重新校验、合并清单和打包：

```sh
npm run archive:package
```

打包脚本使用 Python 3 标准库。重新获取原文的脚本位于 `scripts/archive-*.py`，需要 `requests`，会校验缓存并遵守限流；具体许可、版本、缺失项及复跑说明见 `docs/sources/archive-*.md`。每个原件保留其原有署名、非商业使用或相同方式共享等许可条件。

正文可离线运行；在线字体不可用时自动回退系统字体。资料外链需要网络。笔记只存在当前浏览器 localStorage，清除浏览器数据会删除。

## 五行与术数工具

“五行与干支”和“术数工坊”提供基础查询与规则演算。六爻支持八宫纳甲、六亲与世应，本变卦并列；大六壬支持天地四课、旬空与九宗门三传，显示涉害计克等步骤；太乙支持手动盘位的主客算、逐宫加数、大小将。小六壬与梅花功能保留，三步行宫演示单独折叠。工具可导出完整 JSON。小六壬、梅花和大六壬可一键读取当前时间，按北京时间填入农历、干支和中气月将；仍可手动修改。太乙宫及二目盘位需人工核定。详见 [排盘规则、版本与古例](docs/traditional-methods.md)。

`public/resources/methods/` 新增《增删卜易》《六壬大全》卷一、卷七、《太乙秘书》及《梅花易数》卷二五篇文章的 HTML/TXT 全文，独立清单记录出处、修订、许可与哈希。资料页及工具页均可页内阅读。此批独立于旧版十来源 ZIP；`rules.html` 为可离线阅读的项目规则整理。重新获取：`python scripts/archive-methods.py`；更新规则阅读版：`python scripts/render-method-rules.py`。

资料页新增页内全文阅读器，支持字号、行距与浅深背景；原文归档状态折叠，正文与索引区优先展示。

五种术数均提供随盘更新的结果解说：总览、逐项传统含义、现实观察建议与来源范围。可选择解说主题、记录所问之事，完整解说随 JSON 导出。说明见 `docs/traditional-methods.md` 的“结果解说”部分。

“使用当前时间”按北京时间、00:00换日、正月初一换年，并按中气时刻设置大六壬月将。六爻和太乙仅记录参考时间，保留现有卦与盘位。取时快照、约定和手动调整标记随 JSON 导出。历法依赖 `lunar-typescript@1.8.6`（MIT，首次取时才加载），许可见 `public/licenses/lunar-typescript.txt`，详细来源与边界测试见规则文档。

结果解说默认按问题关键词选择已有规则，支持手动更正。新增梅花“天时天气”主题：按《梅花易数》天时占不分体用、全观本互变卦的规则，回应天气问题并列取象依据。其他工具未实现的天时断法明确提示并可切换梅花。未接入实时气象数据，不输出实际天气、温度或概率。


## 时辰、节气、天文与历法

新增“天文与历法”（`#calendar`）：24小时—十二时辰查询、1901—2100年二十四节气交接表、24节气南北代表地区农事、公历闰年检验，以及18篇详细知识。传统时辰通常一日12个，对照现代24小时；“24时辰”的常见混称在页内说明。工坊入口加入可展开的六项使用注意事项，知识页提供完整版本。

知识同源数据为 `src/calendar-knowledge.json`；由 `python scripts/render-calendar-knowledge.py`（或 `npm run knowledge:render`）生成 [项目知识整理](docs/calendar-and-astronomy.md) 与 `public/resources/calendar/guide.html`、`guide.md`，可在资料页或知识页离线阅读和下载。包括22条权威/实现出处链接；文字是项目原创综述。农事说明按地域、作物生育期、墒情与天气理解，不作为固定全国播期。原十条资料归档包范围保持原样。

三维展示使用本地打包的Three.js与Astronomy Engine 2.1.19（MIT）。日地月位置按1901—2100年所选北京时间计算，支持当前时间、实时与加速播放、分至朔望跳转。半径与距离共用10,000km/场景单位，太阳、地球和月球使用NASA平均半径；可定位各天体、缩放和放大观测窗口。球体、光照和阴影为几何近似，忽略地形、大气和精密食接触计算。

星宿默认地面视角，可选择城市或填写经纬度、海拔；按时间进行岁差章动、地球自转与地平坐标换算，显示方位、高度和地平线遮挡。太阳月球计入站点视差并按实际角直径投影；恒星以未分辨点光源标记。可转向所选星宿、调整视场、切换外部天球总览。未计算恒星自行、地形、大气折射及实际天气。

`src/star-knowledge.json`保存28个同名星官的Stellarium连线与HYG v4.0中所需160颗恒星的J2000.0赤经、赤纬和视星等，连线不代表宿界。生成器将其同步至`public/resources/calendar/star-data.json`供下载；数据署名、上游链接、改编范围及CC BY-SA共享许可见`public/licenses/star-data.txt`，Three.js许可见`public/licenses/three.txt`。导入脚本为`scripts/import-star-knowledge.py`；输入文件的SHA-256保存在数据provenance字段。所有运行时模型与星表均无需外部贴图或网络请求。
