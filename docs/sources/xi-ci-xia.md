# 《周易·系辞下》节选

- 文献：《易传》传世文本。
- 位置：第一章、第二章。
- 核对来源：[维基文库《易传／系辞下》](https://zh.wikisource.org/wiki/易傳/繫辭下)。
- 访问日期：2026-10-29。
- 文本性质：公共领域古典原文，繁体字，以下均为节选。

## 原文摘录

第一章：

> 八卦成列，象在其中矣；因而重之，爻在其中矣；剛柔相推，變在其中矣；繫辭焉而命之，動在其中矣。

第二章：

> 古者包犧氏之王天下也，仰則觀象於天，俯則觀法於地，觀鳥獸之文，與地之宜，近取諸身，遠取諸物；於是始作八卦，以通神明之德，以類萬物之情。

## 项目整理

首页“仰则观象于天，俯则观法于地”据第二章。这里记载的是经典中的文化叙事，单凭这段文字不能确定八卦的考古起源和年代。

“因而重之”提供重卦学习的文本入口。现代组合模型把一个下卦与一个上卦组成有序对，每个位置可选八种，于是有 8 × 8＝64 个结构。上下次序不可忽略；网站组合数组仍从下往上保存六个位置。该计数没有涉及传统六十四卦的卦序或各卦经文解释。
