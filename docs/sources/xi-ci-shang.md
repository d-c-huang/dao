# 《周易·系辞上》节选

- 文献：《易传》传世文本。
- 位置：第五章、第十一章。
- 核对来源：[维基文库《易传／系辞上》](https://zh.wikisource.org/wiki/易傳/繫辭上)。
- 访问日期：2026-10-29。
- 文本性质：公共领域古典原文，繁体字，以下均为节选。

## 原文摘录

第五章：

> 一陰一陽之謂道：繼之者善也，成之者性也。

第十一章：

> 是故易有太極，是生兩儀，兩儀生四象，四象生八卦，八卦定吉凶，吉凶生大業。

## 项目整理

首页“一阴一阳之谓道”据第五章。两仪、四象、八卦是经典中的传统表述。若在现代模型中让每一爻只有两种状态，那么增添一爻就使可能的结构数加倍，得到 2、4、8；这个数学推导依据二值串的定义与乘法原理。

所引文字没有写出 0、1 的位权、进位与加减算法。用现代数学解释其结构，不等于证明经传已经完整表述现代二进制算术。本站的“初爻为最低位”约定也不是这段经文给定的古代规则。
